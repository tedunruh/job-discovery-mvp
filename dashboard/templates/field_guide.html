Buttons & links

Forest leads. If Scout wants you to move, Forest shows you where to go.

Primary button

Use for the one action Scout wants you to take next. At most one per view.

.fg-button.fg-button--primary
Default
Disabled
Block (full width, narrow forms)

Secondary button

Use for an alternate or exit action that shouldn't compete with the primary, like Sign out.

.fg-button.fg-button--secondary
Default
Disabled

Ghost button

Use for navigation that sits in a header or toolbar, where an outline would be too loud.

.fg-button.fg-button--ghost
DefaultRole preferences
Disabled

Button: working state

Use when a button starts something that takes a moment (sending an email, saving). It keeps its own colors and width, the label says what is happening, and a spinner sits before it. Not disabled: focus stays put and a screen reader hears the new label.

.fg-button[aria-busy="true"][aria-disabled="true"] · .fg-spinner

Messages

Color supports meaning; it never carries it alone. The signal color sits in the fill and left rule; the words stay Ink.

Message

Use for a short status the person should read now. Success for confirmations, Attention (Clay) for problems, Discovery (Goldenrod) for "found something for you".

.fg-message.fg-message--success | --attention | --discovery
Success

If that email is on the list, a sign-in link is on its way.

Attention

That link is invalid, expired, or already used.

Discovery

Hey, I found something for you: 3 new roles match your profile.
